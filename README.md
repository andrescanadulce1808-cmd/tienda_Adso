# Taller 3 ADSO - API de tienda (FastAPI + MySQL/MariaDB)

1. Ejecutar sql/01_esquema.sql y luego sql/02_datos_prueba.sql (una sola vez).
2. Crear entorno virtual e instalar: python -m pip install -r requirements.txt
3. Copiar .env.example a .env y completar credenciales.
4. Ejecutar desde la raíz: fastapi dev app/main.py
5. Abrir http://127.0.0.1:8000/docs
